## عن المشاريع

أبني منصات ويب متكاملة في المجالين التعليمي والإداري. معظم المشاريع تخدم جمعيات ومؤسسات خيرية.

**التخصصات:**
- واجهات تفاعلية بـ React + TypeScript + RTL
- - أنظمة Serverless على Cloudflare Workers + D1
  - - تطبيقات Laravel للأنظمة الإدارية الكاملة
    - - أتمتة العمليات عبر Google Apps Script
